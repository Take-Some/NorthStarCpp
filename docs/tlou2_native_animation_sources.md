## Ellie
Command from NorthStarCpp repository root:
    python tools/native_ice_banks.py --character ellie

- 37 source anim-ellie-* PAK banks from sp-common/actor97.
- 6,225 native compressed ICE buffers exported (86,850,528 bytes).
- 4 PAK ANIM records lack directly resolvable local pointer fixups.
- Per-bank JSON manifests preserve clip names, offsets, source SHA256, ICE header bytes.
- 72 earlier Ellie skeleton ICE clips are preserved separately at
  engine/northstarcpp/resources/sharedAssets/characters/ellie/source/native_animations/.
- Do not confuse compressed source buffers with decoded bone keyframes.

## Isaac
The 5,082,077,906-byte world-forward-base.psarc was successfully extracted
into private archives (1,045 PSARC entries).

Command:
    python tools/native_isaac_scene_sources.py

- Six scene PAKs: seq-fob-isaacs-refusal=010 through =060.
- Each contains three explicit ANIM resource names starting with isaac=.
- 18 native references total, not 18 separately decoded animation clips.
- Six original ANIMMAGICSTR cinematic STM streams and six original PAK metadata
  packages preserved in animations/isaac/cinematic_streams/ with SHA256 validation.
- Each STM contains multiple actors; Isaac channels are not individually decoded.
