# NorthStar Animation Lab

A compact test project for OBJ mesh and native Scene V3 animation contracts.
The NEF8 v2 scene contains a player, OBJ pedestal, and an animated cube
with stable entity ID 3. The clip moves the third object upward by four
meters over two seconds. The project JS script starts/stops that animation.
Standalone JS runtime execution requires a verified V8 provider.
